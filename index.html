Integration incidents

Detect: Required field fails schema validation.
Protect: Reject before downstream write.
Record: Store structured validation error.
Recover: Correct payload and safely replay.
Detect: Event ID already processed.
Protect: Skip duplicate side effects.
Record: Log duplicate receipt.
Result: One source event creates one downstream action.
Detect: Downstream API returns 429.
Protect: Do not discard event.
Recover: Retry with bounded exponential backoff.
Escalate: Dead-letter after retry budget is exhausted.
Detect: Temporary service failure.
Protect: Preserve original payload and correlation ID.
Recover: Queue for replay.
Verify: Confirm downstream acknowledgement before marking delivered.

Engineering principle

RECEIVE → VALIDATE → DELIVER → VERIFY

A successful HTTP request is not enough. Reliable integrations protect data, prevent duplicate side effects, preserve failed events, and make failures diagnosable.
